# NeuroDetect 🧠

### Alzheimer's Disease Classification Using Deep Learning

NeuroDetect is an AI-assisted research project that explores Alzheimer's disease classification using MRI images and a hybrid deep-learning architecture combining ResNet50 CNN feature extraction with a Feedforward Neural Network (FFNN).

## 🎯 Objectives

- Develop an MRI-based Alzheimer's disease classification system.
- Extract meaningful image features using ResNet50.
- Classify MRI images into four categories using an FFNN.
- Evaluate model performance using standard classification metrics.

## 🧠 Classification Categories

- Non-Demented
- Very Mild Demented
- Mild Demented
- Moderate Demented

## ⚙️ Model Architecture

```text
MRI Images
    ↓
Image Preprocessing
    ↓
ResNet50 CNN
    ↓
Feature Extraction
    ↓
Feedforward Neural Network (FFNN)
    ↓
Four-Class Classification
```
